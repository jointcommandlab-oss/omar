# Cycling AE (سايكلنج AE)

منصة سايكلنج إماراتية — React + TypeScript + Vite + Tailwind. إعادة بناء مستقلة بلا Base44.

## المرحلة 1 (مكتملة)
- واجهة عربية RTL افتراضياً مع تبديل للإنجليزية، ووضع فاتح/داكن.
- هيدر + قائمة جوال + فوتر + سلايدر رئيسي + حالات فارغة.
- كل روابط القائمة تعمل (الرئيسية، المسارات، البطولات، المتجر، AI Advisor، الإنجازات، المستعمل، الاشتراك، الإعدادات) وصفحات "قريباً" (الملف الشخصي، الإشعارات، السلة، الإدارة).
- المحتوى عيّنات موسومة: لا أرقام مسافات مُختلقة، ولا مستخدمون حقيقيون، ولا دفع فعّال.

## التشغيل
    npm install
    npm run dev      # معاينة محلية
    npm run build    # بناء الإنتاج في dist/

Cloudflare Pages: Build command `npm run build`، Output `dist` (ملف `public/_redirects` يضمن عمل الروابط).

## افتراضات
- الصور بدائل متدرجة حتى تُؤكَّد حقوق الصور.
- أسعار الاشتراك (31 / 352 د.إ) أمثلة قابلة للتعديل؛ نسبة التوفير تُحسب (≈5%).
- الإحصاءات من `src/services/stats.ts` (تجريبية الآن، Supabase في المرحلة 5).
- `.env.example` أسماء متغيرات فقط؛ لا مفاتيح سرية في الواجهة.
